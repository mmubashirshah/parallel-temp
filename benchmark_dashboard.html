1. 2D Grid Scaling: Total Time vs Grid Dimension

Evaluates execution and communication scaling across 30 distinct 2D grid configurations (4 to 30 EV nodes, up to 31 total MPI processes). Demonstrates how Version 2 non-blocking communication (MPI_Isend, MPI_Irecv, MPI_Waitall) consistently outperforms Version 1 blocking (MPI_Sendrecv) by removing serialisation pauses across all grid sizes.

2. Topology Scaling Comparison: 1D Line vs 2D Grid

Direct Empirical Answer to Question (b): In a 1D line topology (1 × N, network diameter N − 1), nodes have at most 2 immediate neighbours. Local charging vacancies saturate quickly, triggering widespread Base Station alerts. In contrast, a 2D grid (diameter 2√N) provides 4 neighbours, absorbing traffic fluctuations locally.

3. Empirical Speedup Ratio: Non-Blocking vs Blocking Baseline

Calculated as Time(Blocking) / Time(Non-Blocking) for each exact 2D grid configuration. The dashed green line indicates the parity threshold (1.0×). As network density grows, asynchronous non-blocking message passing eliminates waiting delays during simultaneous peer probing.

4. Base Station Contention: Alert Frequency in 1D vs 2D Layouts

Demonstrates the root cause behind Question (b) performance divergence. In the 1D line, limited routing paths force up to 61 fallback alerts directly to the central Base Station. In the 2D grid, 4-way spatial adjacency routes overflow locally, capping peak central alerts at 32.

5. Base Station Communication Latency (Microseconds)

Communication latency measured at the Base Station coordinator using MPI_Wtime(). Compares Blocking vs Non-Blocking coordinator overhead as node count increases.
